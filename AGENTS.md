# Project instructions

- Python targets 3.11 and uses typed, async-first interfaces at process boundaries.
- Vue code uses TypeScript strict mode and Composition API.
- Every feature change requires a focused automated test.
- Never commit secrets, generated datasets, model weights, worktrees, logs, or task repositories.
- Agent tools must return the shared structured result contract and enforce workspace boundaries.
- Git commit, push, pull-request creation, destructive commands, and network-enabled execution require explicit approval.
