# 智效工坊 - 简历项目描述（证据版）

> 项目名：智效工坊｜AI 全栈软件工程 Agent
> 角色：架构、Agent Core、FastAPI、Vue、Worker、部署与测试
> 说明：本页只陈述仓库中已有代码和测试；真实模型效果指标在固定评测完成前不填写。

## 项目经历

- 使用 LangGraph `StateGraph` 实现仓库探测、计划审批、隔离 worktree、工具循环、测试、自修复和 Diff 交付，并以 SQLite checkpoint 支持进程重启后的 interrupt/resume。
- 构建 4 级权限和类型化工具系统，覆盖文件、搜索、精确编辑、命令、测试、Git、Todo、后台任务、网络、知识、子 Agent 与 MCP；危险命令、联网 clone 和发布操作进入审批门禁。
- 开发 FastAPI 控制面和 Redis Streams Worker，持久化 TaskRun、步骤、工具调用、审批、Diff、测试与制品，提供可断线续传 SSE 和 63 条 OpenAPI 路径。
- 使用 Vue 3、TypeScript strict、Pinia 与 Element Plus 实现仓库、任务、审批、终端、Diff、工作流、Agent、模型、微调、知识图谱和评测控制台。
- 建立 Chroma/Milvus 向量抽象与双写迁移、Neo4j 混合召回、训练数据去敏、PEFT LoRA、模型注册、vLLM 启动配置和 A/B 路由。
- 建立 Ruff、Mypy、Pytest、Vitest、Playwright、Alembic、Bandit、依赖审计、Compose 冒烟、GPU 训练和 Release 工作流；本地测试数量与 CI 结果以对应运行制品为准。

## 技术栈

Python 3.11、LangGraph、FastAPI、SQLAlchemy async、Pydantic v2、Alembic、Redis Streams、MySQL、Vue 3、TypeScript、Vite、Chroma、Milvus、Neo4j、PEFT/TRL、vLLM、Docker Compose、GitHub Actions。

## 量化数据使用规则

任务完成率、首次通过率、成本、延迟、召回率与幻觉率只允许从 `tests/evals/scenarios.json` 对应的真实结果制品生成。当前没有外部模型密钥和 GPU/百万级基准证据，因此不写入推测百分比。
