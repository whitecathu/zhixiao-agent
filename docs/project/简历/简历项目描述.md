# 智效工坊 - 简历项目描述（证据版）

> 项目名：智效工坊｜安全的软件工程 Agent harness
> 角色：架构、Agent Core、FastAPI、Vue、Worker、部署与测试
> 说明：本页只陈述仓库中已有代码和测试；真实模型效果指标在固定评测完成前不填写。

## 一句话

做的是**安全的软件工程 Agent harness**（权限 × worktree × 验证门禁 × 插件组装），不是多 Agent 内容平台，也不是已交付的 LoRA / 百万向量召回微调控制台。

## 项目经历

- 用 PluginHost 统一组装 CLI / TUI / Worker：`load_plugin_tree` 贡献工具、斜杠命令、hooks、Skill、MCP；未信任工作区跳过 `.zhixiao/plugins`。CI 含 `zhixiao plugins doctor` 烟测。
- 四级权限（`read_only` / `edit` / `execute` / `full`）叠加 ops/network 审批；`CommandPolicy` 在无审批时拦截 `git push`、`rm -rf`；工具路径限制在声明的 workspace 根目录。
- 默认执行图是单个编码 Agent 的工具循环（intake→discover→plan→execute→verify→finalize）。LangGraph `StateGraph` + SQLite `AsyncSqliteSaver` 支持计划审批 interrupt 与协同停止：runtime 消费 `{state_dir}/control/{run_id}` 后 `interrupt(operator_stop)`，同一 run_id 可 resume。`routing.py` 的 planner/explorer 是事件标签，不是独立 Agent。
- 构建 FastAPI 控制面与 Redis Streams Worker（队列/SSE，不是图 checkpointer），Vue 3 + TypeScript strict 负责任务、审批与「运行证据」条：权限模式、验证结果（缺失显示「未回报」，不编造「已通过」）、终止原因、用量快照。
- 离线行为门禁 `tests/evals/run_behavioral.py`（ScriptedModel）覆盖危险命令拦截、interrupt/resume、ask 只读；`offline_harness_results.json` 只证明报告管线，不是任务完成率或幻觉率。

未上线实验切片（包存在、不作交付成果）：向量抽象 / PEFT LoRA / vLLM 启动配置等 CPU stub；GPU 训练与百万级召回**未实测**。Workflow DSL 与 MetaGPT Team 是可选引擎，不是默认产品叙事。

## 技术栈

Python 3.11、LangGraph、FastAPI、SQLAlchemy async、Pydantic v2、Alembic、Redis Streams（任务队列与 SSE）、MySQL、SQLite checkpoint、Vue 3、TypeScript、Vite、Docker Compose、GitHub Actions。Chroma / Milvus / Neo4j / PEFT / vLLM 仅为可选依赖与实验切片。

## 量化数据使用规则

任务完成率、首次通过率、成本、延迟、召回率与幻觉率只允许从真实评测制品生成。`tests/evals/fixtures/offline_harness_results.json` 是 provenance，禁止写成质量分数。当前没有外部模型密钥和 GPU/百万级基准证据，因此不写入推测百分比。`packages/agent_core/pyproject.toml` 的 `version = "1.0.0"` 不是已发布版本。
