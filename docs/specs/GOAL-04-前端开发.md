# GOAL-04: 前端应用开发（Vue3+TS 工程化前端实现）

## 需要调用的Skill
| Skill名称 | 用途 |
|-----------|------|
| `vue-expert` | Vue框架专家 |
| `frontend-developer` | 前端开发 |
| `frontend-patterns` | 前端开发模式 |
| `software-frontend` | 生产级前端 |
| `typescript-pro` | TypeScript专业开发 |

## 执行目标
基于Vue3 + TypeScript + Element Plus开发「智效工坊」平台前端应用，遵循工程化开发规范，实现完整交互体验。

## 角色定位
资深前端工程师

## 技术约束
- 技术栈：Vue 3.4+ Composition API + TypeScript 5.4+ + Pinia状态管理 + Vue Router 4 + Axios
- UI组件：Element Plus 组件库，统一设计规范
- 工程规范：ESLint + Prettier 代码格式化，组件化拆分，类型定义完整
- 性能要求：首屏加载优化、按需引入、路由懒加载

## 核心页面与功能要求

### 1. 登录注册页
- 表单验证、错误提示、密码强度校验
- 登录状态持久化、令牌自动刷新、过期无感重登
- 支持切换注册/登录模式

### 2. 工作台首页
- 概览统计卡片：任务数、知识数、今日执行量、复用率
- 快捷任务创建入口，支持常用任务模板
- 最近任务列表，展示状态与进度
- 最新知识推荐

### 3. 任务执行页（核心页面）
- 任务目标输入区，支持附件上传
- 执行过程可视化：时间轴节点展示Agent执行步骤，节点区分状态（待执行/执行中/已完成/失败）
- 点击节点可展开查看该步骤的详细输入、输出、调用的工具、耗时
- 内容输出区：流式渲染生成内容，支持Markdown渲染、代码高亮、公式渲染
- 操作栏：中断任务、重新执行、导出成果、复制内容

### 4. 知识看板页
- 左侧分类标签树，支持多级分类与标签筛选
- 智能搜索框，支持语义检索，高亮匹配内容
- 知识卡片列表，展示标题、摘要、标签、来源
- 知识详情页：完整内容、关联任务、相关知识推荐

### 5. 团队与个人中心
- 个人信息修改、密码修改
- 团队空间管理：空间信息、成员列表、邀请成员、角色权限设置

### 6. 通用交互
- 全局加载状态、统一错误提示、确认弹窗
- 响应式布局，适配1366~1920桌面分辨率
- 深色/浅色主题切换

## 工程与代码要求
1. 完整的项目目录结构，按页面/组件/工具/状态/路由分层
2. Axios封装：请求拦截器（鉴权、请求头、参数格式化）、响应拦截器（统一处理错误码、令牌刷新、数据脱敏）
3. Pinia状态管理：用户模块、任务模块、知识模块，定义清晰的state、getters、actions
4. 路由配置：路由守卫、权限控制、懒加载、404页面
5. 核心组件实现：
   - 任务执行时间轴组件
   - Markdown渲染组件
   - 通用搜索框组件
   - 分页表格组件
6. 核心页面的完整Vue组件代码，附带详细注释
7. 类型定义文件：所有接口请求/响应数据的TS类型声明
8. 环境变量配置：区分开发/测试/生产环境
