# GOAL-05: 容器化部署与工程化运维

## 需要调用的Skill
| Skill名称 | 用途 |
|-----------|------|
| `docker-expert` | Docker容器专家 |
| `docker-patterns` | Docker架构模式 |
| `deployment-patterns` | 部署模式 |
| `devops-engineer` | DevOps工程师 |
| `sre-engineer` | SRE可靠性工程 |

## 执行目标
为「智效工坊」平台设计完整的Docker容器化部署方案与上线运维流程，实现一键部署、可观测、易排查。

## 角色定位
DevOps工程师 / 全栈运维工程师

## 部署架构
Docker Compose 统一编排5个服务：FastAPI后端服务、Vue前端（Nginx托管）、MySQL 8.0、Redis 7.0、Chroma向量库

## 核心输出要求

### 1. 各服务Dockerfile编写
- **后端**：Python多阶段构建，精简镜像体积，安装依赖优化，时区配置
- **前端**：Node构建+Nginx运行多阶段构建，静态资源压缩
- **数据服务**：官方镜像基础上配置初始化脚本、数据卷挂载

### 2. Docker Compose 编排文件
- 服务依赖关系配置、启动顺序控制
- 统一网络配置、端口映射
- 数据卷持久化配置，防止数据丢失
- 环境变量注入，敏感信息不硬编码

### 3. Nginx配置
- 前端静态资源托管，开启gzip压缩、浏览器缓存
- 后端接口反向代理，处理跨域、请求超时配置
- SSE流式接口的特殊配置（关闭缓冲、超时设置）
- 访问日志、错误日志配置

### 4. 环境变量管理
- 区分开发、测试、生产三套环境配置
- 敏感信息（数据库密码、LLM密钥等）通过环境变量注入
- 配置文件模板与示例

### 5. 测试验收方案
- **接口测试**：核心接口的测试用例与预期结果
- **功能测试**：完整业务流程的测试点清单
- **AI效果测试**：任务完成率、知识召回率、输出合格率的评估方法与评分标准

### 6. 上线运维手册
- 从零开始部署的完整操作步骤
- 服务启动、停止、重启、日志查看的命令
- 常见故障排查指南：服务启动失败、接口报错、AI执行异常、数据丢失等
- 数据备份与恢复方案

### 7. 可观测性基础方案
- 日志规范：分级日志、链路ID追踪
- 基础监控：服务存活状态、资源占用
- 告警基础：核心服务异常的告警触发条件

## 输出文件清单
1. `backend/Dockerfile` - 后端镜像构建文件
2. `frontend/Dockerfile` - 前端镜像构建文件
3. `docker-compose.yml` - 服务编排文件
4. `nginx/nginx.conf` - Nginx配置文件
5. `.env.example` - 环境变量模板
6. `.env.dev` / `.env.prod` - 开发/生产环境配置
7. `deploy/` - 部署脚本目录
8. `docs/运维手册.md` - 运维文档
